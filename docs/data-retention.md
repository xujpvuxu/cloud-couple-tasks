# 任務紀錄保留七天

完成或遭駁回的任務、遭拒絕的兌換申請，以及已確認使用的獎品，會依各自結束時間保留七天，再由 GitHub Actions 每日清理。尚未完成、等待驗收、等待對方確認，或已兌換但尚未使用的獎品不清理。任務完成後由發布者驗收；只有驗收成功時才會將點數加入帳戶。駁回的任務不會發放點數。兌換申請由另一半確認後才扣點，獎品會進入申請者的獎品區；申請使用時需再經另一半確認，確認後才移到已兌換並開始計算七天。七天清理不會改動已入帳或已扣除的帳戶點數。

首次啟用前，請先將儲存庫的 `firestore.rules` 發布到 Firebase，再於 GitHub 儲存庫設定 `FIREBASE_SERVICE_ACCOUNT` Actions secret。該服務帳戶需要 Firestore 資料庫寫入權限。

可在 GitHub Actions 手動執行 **Retain task history for seven days**。清理腳本會用交易處理舊版尚未遷移的已完成任務點數，避免清除紀錄時遺失點數；工作中斷時，未處理的資料會留待下次執行。
